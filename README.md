# ClevBell: Dual Mode Gym Equipment with Modular Load System

A compact and versatile gym machine designed for home and small workout spaces.  
ClevBell supports both **lat pull-down** and **low-row/pushdown** exercises using **linear guide rails** and a **modular load system** that accommodates standard dumbbell disks instead of proprietary weight stacks.

---

## 📌 Abstract
Modern fitness enthusiasts need **space-efficient**, **affordable**, and **adaptable** equipment.  
ClevBell addresses this gap by combining two modes of cable-based resistance training in a single unit.  
Key features:
- Dual-mode functionality: **pull-down** (upper pulley) and **pull-up/low row** (bottom pulley).  
- Modular load system: supports **user-owned dumbbell plates**.  
- Compact and portable design: frame optimized for **home gyms**.  
- Workshop-friendly fabrication: relies on **readily available materials** and simple manufacturing processes.  

---

## ⚙️ Design Methodology
1. **Need Identification & Benchmarking**  
   Compared with commercial lat machines, home pulley setups, and resistance bands.  
   ClevBell emerged as the only design offering **dual functionality + dumbbell compatibility** at a medium cost.  

2. **Concept Generation**  
   - Vertical frame with **linear guide rails**.  
   - Three fixed pulleys (two top, one bottom).  
   - Detachable cable system for mode switching.  
   - Weight holder bar with dumbbell disks.  

3. **Embodiment Design**  
   - **Frame:** Aluminum base (45×60 cm, asymmetric legs for stability).  
   - **Guide rails:** Cast iron carriage for smooth linear motion.  
   - **Pulleys:** HR Steel shaft with stainless steel pulleys.  
   - **Bolted modular assembly** for portability.  

4. **Design Calculations**  
   - Linear guide rail factor of safety: **14.5**  
   - Pulley shaft safety factors: **ny = 4.48, nf = 5.67** (safe under fatigue).  
   - Rope safety factors: **ny = 33.36, nf = 21.28**  
   - Weight holder: fracture **n = 5.67**, fatigue **n = 11.28**  

5. **CAD Models & BOM**  
   Complete part and assembly drawings + Bill of Materials included in `/cad/`.  

---

## ✅ Key Results
- Successfully designed a **dual-mode pulley system**.  
- Achieved **compact footprint** with **stable base support**.  
- Validated safe operation under **expected user loads** with **high safety factors**.  
- Allows **quick switching** between pull-down and pull-up exercises.
